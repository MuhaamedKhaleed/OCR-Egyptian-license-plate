# Explicit transcription-order adapter

The legacy `decode_characters`, `predict_plate` and `predict_plates` APIs retain their documented spaced output with both groups sorted right to left. Do not pass that output to the strict text evaluator by only removing spaces: its digits would be reversed relative to the evaluator's visual-left-to-right contract.

The new pure helper `egypt_plate_ocr.transcription.transcription_from_characters` accepts the existing `Detection` objects for one already-localized, single-row plate crop. It returns unspaced `letters_rtl` in logical right-to-left reading order and `digits_ltr` in visual left-to-right order. Supply the exact same stable ID to prediction and truth records before calling `scripts/plate_text_metrics.py`. Both groups use the existing audited class-to-Unicode mapping, including Arabic-Indic digits. There is no hidden normalization or correction.

Fictional coordinate wiring example: digit classes 1, 2, 3 at x=10,30,50 return digits_ltr=١٢٣, while letter classes alef, baa, seen at x=100,80,60 return letters_rtl=أبس. Legacy output for the same fixture remains numbers=٣ ٢ ١ and letters=أ ب س. Neither output is a model prediction.

Callers must remove duplicate boxes, retain raw character coordinates and isolate one plate before this helper. It deliberately rejects unknown classes rather than silently discarding possible errors. Filter plate-localization boxes explicitly before calling. Equal x centers within a group fail as ambiguous. Empty input returns two empty groups, so a failed prediction remains countable. Partial groups are preserved. More than 32 characters per group fails, matching the evaluator's input limit. This helper does not detect duplicate boxes with different centers, stacked rows, rotations, multiple plates, missing characters or false positives. It is not yet a new CLI inference mode and does not change existing inference behavior.

Eleven new offline regression tests cover opposite orders, 100 fixed-seed input shuffles, exact Unicode aliases, legacy compatibility, empty and partial failures, unknown classes, center ties, size limits and end-to-end pairing with the strict evaluator. These tests prove the wiring convention, not real OCR accuracy. No dataset, weights, real registration text, fees or score increase. New owned code is MIT; model and data rights remain separate. Review branch only, no main merge.
